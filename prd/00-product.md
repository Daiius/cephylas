# 00. プロダクト

本章はこのアプリが**何をするものか**を定める。技術構成は [01](./01-architecture.md)、
core は [02](./02-core.md)、web は [03](./03-web.md)、公開範囲は [04](./04-access-and-privacy.md) に委ねる。

## 目的

**Docker コンテナごとのリソース使用率を記録し、直近 24 時間の推移をグラフで見る。**
対象は作者の本番 VPS で、複数の Web アプリがコンテナとして同居している。
「どのコンテナがいつ重かったか」を、サーバに入らずブラウザで確かめられることが価値である。

もともとは Linux の `/proc` 以下を読むロガーとして作り始めた。本番は Docker で管理しており、
欲しいのはホスト全体ではなく**コンテナ単位**の数字だったため、Docker Engine API を使う形に
書き直した経緯がある。

副次的な目的が 2 つある。

- **少ない依存で低レベルから作る。** core は Docker Engine API への HTTP リクエストも、
  REST API のサーバも自前で書いている。外部 crate は `json` だけである。
  これは**方針**であり、破ってはならない制約ではない（[01](./01-architecture.md) §設計方針）。
- **Next.js でのデータ可視化を試す。** Server Component でのデータ取得、`'use cache'` による
  キャッシュ、Partial Prerender を実際に動くアプリで確かめる。

## 利用者の範囲

**主な利用者は作者本人**である。運用中の VPS の様子を見るために使う。

現状は**認証が無く、URL を知っていれば誰でも見られる**。これは意図した公開であり、
作品として見せる性格を持つ。**Cloudflare Access による制限を計画している**
（[04](./04-access-and-privacy.md)）。制限を入れたあとの利用者は、Access が許可した者に限られる。

## 非目標

次は**やらない**と決めているものである（「まだやっていない」ではない）。

| 非目標 | 理由 |
|---|---|
| アプリ自身でのログイン機能・利用者管理 | 閲覧の制限は前段（Cloudflare Access）に任せる。core にも web にも認証を実装しない |
| 通知・アラート（しきい値超過のメールなど） | 見たいときに見る道具で足りる |
| コンテナの操作（起動・停止・再起動） | 読み取り専用に閉じる。Docker ソケットへは GET しか送らない |
| ホスト全体の統計（コンテナ外のプロセス） | コンテナ単位が欲しかったのが出発点である |
| 複数ホストの集約 | 1 台の VPS を見る道具である |

⚠ **24 時間より長い期間の表示は非目標ではない。** 週・月単位へ要約して残す構想があり、
当面やらないだけの**検討事項**として扱う（[02](./02-core.md) §ログの保持）。

## 画面と操作

画面は **2 つ**である。

| パス | 役割 |
|---|---|
| `/` | 4 種のチャート（CPU / メモリ / IO / ネットワーク） |
| `/about` | アプリの紹介と名前の由来。`← Charts` で `/` に戻る |

`/` は上から順に次の 4 枚を縦に並べる。横軸はいずれも時刻で、全コンテナを 1 枚に重ねて描く。

| チャート | 縦軸 | 系列 |
|---|---|---|
| CPU usage (%) | % | コンテナごとに 1 本 |
| Memory usage (%) | % | コンテナごとに 1 本 |
| IO speeds (kBps) | kBps | コンテナごとに read（実線）と write（破線） |
| Net speeds (kBps) | kBps | コンテナごとに recv（実線）と send（破線） |

各チャートの上端に**凡例兼フィルタ**を置く。操作は次の 2 つだけである。

- **クリック / タップ**: そのコンテナの表示・非表示を切り替える。
- **ダブルクリック / ダブルタップ**: そのコンテナだけを表示する。すでに単独表示なら全表示に戻す。

フィルタは 4 枚で共有され、どのチャートで操作しても全チャートに反映される。
**状態は保存しない。** リロードすると全表示に戻る。詳細は [03](./03-web.md)。

ヘッダには中央にアイコンだけを置き、押すと `/about` へ移る。ナビゲーションは無い。

**配色はライトテーマのみ**である。Chart.js がダークテーマを持たないため、UI 全体を light に固定している。
